0. 一句话

龙骨 Keel 1.0 = 剧本 / 微短剧的「结构体检 + 合规自检」工具。
形态：一条命令 → 0.5 秒（实测）→ 一份自包含、断网可开、能直接发给别人的 HTML 报告。

它不替你写，也不夸你写得好。它用结构化证据指出你的故事哪里站不住、
用留痕保护你的权益，把每一个「改不改、怎么改」的决定交还给你。

卖点不是「写得更快」——那是加剧那 98.7%。是避免浪费：
在投入制作之前就知道这部结构上有问题。

1. 名字：龙骨 / Keel

为什么换掉 Loom（实测，2026-09-19 查过）

名字判定证据
Loom❌ 不可用已被 Atlassian 收购（2023-11 交割）；开发圈里 "Loom" 还指 Java Project Loom（虚拟线程）
Fabula❌ 更糟同赛道直接占用：fabula.productions 做「剧本→知识图谱」，fabulaos.io 自称 "AI-native OS for story development"
Textus❌ 撞音与 TextUs（短信营销软件）读音完全相同

Fabula 本来是最自然的选择 —— fabula / syuzhet 是叙事学里 IR 与文本的原始对立，
正是本项目「IR 是本体、文本只是视图」的术语来源。但越是精确的名字越可能已经被占：
正因为贴切，同赛道已经挤满了。

为什么是龙骨

吊顶与船体里那层看不见却承重的结构。正对应本项目的立场：
决定一部作品站不站得住的，是正文之下那层结构。

  • 中文母语可读、好记、未被同赛道占用
  • 英文 Keel 是同一件事的另一个说法：先定龙骨，再定船
  • 改名已完成（包名 / CLI / 仓库 / 全部文档），见 CHANGELOG.md

未验证：没有做商标检索。上述只是「软件领域重名调研」，
不等于法律上的可用性判断。真要对公众发布前，这一步必须补。

一个安装上的真实坑（实测 踩到）

Python 3.13 新建的 venv 不含 setuptools，因此 pip install -e .
在离线环境下会以 BackendUnavailable: Cannot import 'setuptools.build_meta' 失败。
两条解法：

# 有网：让 pip 自己拉构建依赖（默认行为，什么都不用改）
pip install -e .

# 离线：先装 setuptools，再跳过构建隔离
pip install setuptools wheel && pip install -e . --no-build-isolation

这条写进交付方案，是因为文档里写错的安装命令比没有文档更贵 ——
用户按它做、做不通、就走了。

8. 不做什么（四条红线 + 三条防过度工程）

不做为什么
不做网文代笔起点/番茄/晋江一致禁止 AI 直出正文。同一套 Keel：做网文是违规工具，做剧本是合规工具。 已实现为 policy.py 闸门
不预测爆款LLM 评委与人类判断反相关（会把零样本 AI 故事排在《纽约客》之上）。只做结构性淘汰
不做反检测技术上徒劳、伦理上站不住、商业上致命。机检红线见 tests/test_redlines.py
不自动改结构只自动修文风；结构类出提案等人裁决。理由一：保护作者意图。理由二（PLOTTER 实测）：图规划路线在前提忠实度上只有 40%
暂不做为什么
Web UI / SaaS部署 + 鉴权 + 成本，与当前规模不匹配的大跃迁
账号 / 计费同上。且定价不该按生成量（那等于激励生产更多失败品）
更多校验器35 个门禁已足够。瓶颈是能不能被看见，不是检查数量

9. 风险与未闭合项

🔴 未闭合：公开仓库的历史泄露（需你决定）

事实（实测）：旧仓库名 loom 的初始提交 48cab2af0ccf… 里，
误提交了 5 份内部记忆文件（约 185 KB 的项目策略/合规/竞品笔记）。

已做的处置：

  • 用 git filter-branch 重写全部历史，.workbuddy-ai/** 从所有分支清除
  • 本地对象库 gc --prune=now，旧提交已不可读
  • force-push，远端 4 个提交全部干净

但仍然没关掉的：旧提交与其 5 个 blob 在 GitHub 上仍可经 SHA 取回
（git fetch origin <sha> 成功；API 仍返回 41779 字节）。
GitHub 只在自家 gc 时丢弃不可达对象，用户无法触发。

「历史已重写」不等于「内容已消失」。 前者是「没人能顺着分支找到」，
后者是「谁都拿不回来」。记录过 SHA 的人仍能原样取回。

两条出路：① 删库重建（彻底，但当前 token 无 delete_repo scope）；
② 找 GitHub Support 跑一次 gc（保留仓库，耗时不定）。

缓解事实：仓库创建于 2026-09-19T09:40Z，0 fork / 0 star / 0 watcher，
暴露窗口约 1 小时；且已扫 sk- / gho_ / ghp_ / AKIA / PRIVATE KEY，零命中 ——
没有凭据泄露，风险落在「内部笔记被读过」，不是「密钥失窃」。
